# IT Support & Networking Fundamentals

This repo shows the first practical skills I built during my City & Guilds Diploma and Microsoft IT Support learning.

## What’s inside
- `troubleshooting_checklist.md` — short, repeatable steps for common PC issues
- `network_diagram.png` (optional later) — simple home/small office network sketch
- `customer_service_case_study.md` — short story of a support case (how I solved it)

## Why this matters
These foundational skills taught me how users think, how to isolate problems, and how to document fixes — all crucial when you later secure and audit systems.
